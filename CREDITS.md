# Third-party assets

Everything else in this repository is written here. These are not, and this is
where they came from.

## Scenery library

The sixty-two scenery meshes behind the SCENERY palette's six "library"
families — trees, plants, boulders, rocks, trunks and temple slabs — are baked
into `src/prop-data.ts` by `tools/bake-props.mjs`. All of them are **CC0 1.0
(public domain)**; credit below is offered because it is deserved, not because
it is required.

| Source | Author | Licence | Used for |
| --- | --- | --- | --- |
| [Nature Kit 2.1](https://kenney.nl/assets/nature-kit) | Kenney | CC0 1.0 | trees, palms, bushes, grasses, bamboo, hanging moss, rocks, boulders, logs, stumps, statues, obelisks, plinths |
| [Graveyard Kit 5.0](https://kenney.nl/assets/graveyard-kit) | Kenney | CC0 1.0 | square pillar, obelisk, carved altar, broken wall, rubble, long dead trunk |
| [Modular Ruins Pack](https://poly.pizza/) | Quaternius | CC0 1.0 | collapsed wall, stub column, loose bricks, inlaid floor |
| Big Leaf Plant | reyshapes (via Poly Pizza) | CC0 1.0 | elephant ear |
| Cobblestone tile | Kay Lousberg (via Poly Pizza) | CC0 1.0 | cobbled path |

Only the GEOMETRY is used. None of these ship with a texture in this game:
each source material is mapped onto a surface role (bark, sawn wood, leaf,
stone, dirt), painted with this game's own surface textures, and tinted from
its own palettes. Positions are requantised to 16 bits,
normals to 8, and UVs are regenerated by box projection — so what is committed
is a derived, re-scaled, re-materialised form of the originals, not a copy of
the distributed files.

To rebuild it, download the kits and run:

```
node tools/bake-props.mjs <dir-of-glbs>... > src/prop-data.ts
```

## HUD display face

Not third-party either, but worth recording where it came from. The HUD
lettering is cut from three hand-drawn alphabet sheets, kept at full resolution
in `art/hudfont-sheet{1,2,3}.png`. They are the only copy of that artwork,
which is why the source sits in the repository rather than just the atlas built
from it.

```
node tools/bake-hudfont.mjs art/hudfont-sheet{1,2,3}.png
```

That writes `public/hudfont.png` and `src/hudfont-data.ts`. The three sheets
overlap rather than divide neatly, so the baker names one source cell per
character:

| Sheet | Holds | Used for |
| --- | --- | --- |
| 1 | A–X and Z, some drawn twice | every letter but Y — it is the widest cut |
| 2 | a partial alphabet, digits, punctuation | the digits and all the punctuation |
| 3 | the complete alphabet and digits | Y, the one letter sheet 1 never drew |

Sheets 1 and 2 are scans on transparent backgrounds, so their alpha channel is
already the ink mask. Sheet 3 is a flat render on cream paper with no alpha at
all, and a colour threshold can't key it — the paper and the white inline
inside each letter are only a few levels apart, so thresholding hollows every
glyph out. The paper is flooded inward from the border instead; the inline is
enclosed by the navy outline, so the flood can never reach it.

The only mark still built rather than cut is `+`, which the trick plate needs
to join tricks and no sheet draws: crossed copies of the face's own dash.

## HUD icons

Same story: the crate and fruit counters are drawn artwork, kept at full
resolution in `art/hud-crate.png` and `art/hud-apple.png`.

```
node tools/bake-hudicons.mjs
```

That writes `public/crate.png` and `public/apple.png`. The originals are
1024px renders sitting in a wide empty margin, and the crate carries a faint
wash of low-alpha pixels across its whole canvas that draws as a dim grey
square over bright scenery. The baker floors the alpha to clear that, trims to
the artwork's own edges so the icon fills its slot, and fits the longest side
to 192px — twice the largest size the HUD ever draws them, and a twentieth of
the bytes.

## Everything else

Levels, physics, the character rig, the surface textures, the editor and the
UI are original to this project.
