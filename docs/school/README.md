# School source measurements

`source-geometry.json` is decoded geometry and rail data for the local measured School preview. It is derived from the School files retained in the retail THPS2 PC pack, not newly authored replacement geometry. Original game material remains attributable to its owners. This task keeps delivery local.

The source file names, byte sizes and SHA-256 hashes are embedded in the JSON. Archive provenance and pack offsets are recorded in `../performance/school-miami-retail-reference.json`. The files have not been independently hash-matched to a THPS1 disc. No executable, texture, sprite image, game archive or third-party decoder implementation is included.

Regenerate from local reference files:

```sh
python3 tools/school-source-survey.py --psx /path/to/SKSCHL.PSX \
  --trg /path/to/SKSCHL_T.TRG --out /tmp/school-summary.json \
  --geometry-out docs/school/source-geometry.json
```

Coordinates are `[X, -Y, Z]` in original whole engine units, before the preview's scale and X reflection. Each mesh stores flat vertex coordinates and faces shaped as `[originalFaceIndex, renderFlags, collisionFlags, R, G, B, ...vertexIndices]`. Original polygon boundary order is retained. The export omits 98 sprite faces; collision-only polygons remain. The level factory rejects seven degenerate polygons and builds the remaining 7,593 faces. Rail records preserve original TRG IDs and directed links. `railActivation.paths` supplies the original normal-start chain boundaries, including overlaps.

The format reader is source-owned Python informed by the pinned format reference listed in its header. Re-exporting the same input files produces a byte-identical JSON file. The preview deliberately uses existing procedural materials; exact original art and complete traversal validation remain future work.

The bounded `Re_Start_School` audit (node 393) resolves the original pulse semantics: command points 3, 506, 608 and 879 activate 128 chains, 331 segments and 270 unique edges. Their 61 overlapping segments are intentional source chain overlap. Alternate-mode command point 961 and its edge 189→190 are excluded. The decoder requires the exact unconditional activator layout and restart-only parentage; unknown instructions, indirect activation and cyclic chains fail closed. It does not execute scripts. See `../performance/school-miami-source-activation.json` for decoded commands, source references and provenance. Validate with `python3 tools/test-school-activation.py /path/to/SKSCHL_T.TRG`.

The restart export also retains its raw angles. School's normal restart has yaw 1023. In the pinned original code, `FudgeAngles` adds 2048 and rotates -Z to make `mFront`, but `HandleKick` accelerates along **negative** `mFront`. After the preview's X reflection, actual starting travel is approximately +X, with a 0.084-degree negative-Z offset. The native cardinal zone remains east; the existing canopy heading was correct. Reading only the rotation function would reverse it.

The animated scale audit is in `../performance/school-miami-source-scale-audit.json`. The shared `tools/psx-skater-survey.py` independently checks all 78 HAWK animation byte budgets, stitches and the 4,096-entry rotation table. Relaxed clip 0 measures a median 208.1875 original units from board bottom to head. Visible vertices of the current rider measure 2.90384 m during coasting; lite and full measurements differ by less than 1e-10 m. Hidden helpers are excluded. The pose measurement button is available in the local preview.

The measured preview now uses that neutral-pose calibration: **2.90 / 208.1875 = 0.0139297508 m per original unit**, 2.993% above its previous provisional scale. The user-facing map reconstruction remains at the accepted 2× size, and the character is unchanged. Differing crouch proportions prevent a single uniform scale from matching every pose; this is a neutral-coast registration, not a claim that all poses match.

At the new scale the original gym toe is 1.978 m high. It exceeded the fork's stock 1.755 m ollie, as the prior nine-distance audit records. The measured preview now opts into `skateReference`, using Tony after the first STAT UPGRADE (ollie 4, speed 8, air 8, balance 5) and **School's own metres-per-unit scale**. The shared implementation comes from local commit `73ddb1615a4e84d42cef830ad5074dbe229a7311`. It converts the original 30 Hz/Q12 gravity, charged pop, auto-kick and drag parameters into the existing fixed-step runtime. It also carries signed slope velocity into ground/rail jumps and allows a fresh, unjumped departure across coping. The profile leaves existing `TUNING` and `SKATE_PARK` values unchanged; the branch-support integration below restores the already-authored default rail-transfer setting.

The calibrated flat ollie peaks at 2.17734 m. Both original gym lips now clear without moving their geometry: the test charges on approach, lands on the bank, brakes and turns below its back wall, then returns to the court. Neutral input in the original game keeps auto-pushing, so the old passive-rollout pilot was inappropriate. Separate flat, rising and falling rail fixtures in both directions verify signed takeoff velocity through actual catch/charge/release inputs. These fixtures do not claim a complete rail-physics port.

This is still a partial movement adaptation. Fixed-point rounding, push-animation gating, temporary crouch-target decay, steering/braking/contact tracking, terrain/special behavior and parts of rail physics differ from the original. The original raised curbs, banks, rail gaps and sharp source corners remain physical geometry.

## Source rail motion

Iteration 29 adopts the rail entry impulse, slope gravity, 30 Hz low-speed assistance, natural runoff and final full-vector speed cap from the pinned original code, with local dependency `fac37fb2e4abced57d85f8588fcb406d85adcb0e`. At School's scale, rail entry adds **5.43260 m/s**, gravity is **39.78957 m/s²**, and the final speed cap is **38.95348 m/s**. A normal runoff adds no pop and carries the full rail-tangent velocity. Charged release happens before rail traversal, including at the final supported sample.

A directional ollie turns the launch velocity **200/4096 of a turn (17.578125°)** within the rail plane. Inspection of `HandleJump` shows that it reads the rider's left/right buttons directly, independent of the camera. The School integration follows that rule and suppresses the fork's additional lateral strafe for this source profile. Sixteen actual input-release checks, covering both travel directions, both side inputs and four camera headings, produce identical camera-independent launch vectors. Separate source-domain traces check 30/60/120 Hz integration, signed 3D catch projection, reversal, runoff, direction and the final speed cap. Six real catch/charge/release fixtures also remain covered.

Original uphill chains 784 and 206 climb **22.1901 m** and **20.2956 m**. Even the final speed cap provides only about **19.067 m** of gravitational head; an 18 m/s entry must reverse downhill. The prior generic minimum-speed clamp incorrectly let these cases creep all the way up. Their current checks require an observed reversal, return through the starting endpoint and a grounded rollout. Both downhill traversals remain covered. No rail point, curb or slope was moved. Two new normal-input courtyard approaches charge from the original planter top and the courtyard floor, ollie onto original chain 163, grind to its end and land in 346 and 276 steps. Both start on verified mesh support (source heights 1764 and 1599); neither rail catch is initialized from midair.

Iteration 29 recorded **19 cases / 11,047 steps**, with matching native and lite/full browser results. Its historical audit is retained in `../performance/school-miami-reference-rails.json`. The balance and landing pass below supersedes those traversal counts.

The working preview's 2× map still passes all 64 cases / 18,054 steps with a byte-identical report. The task branch initially reproduced five older transfer failures, so iteration 29 also integrates the already-authored default transfer implementation from local commit `86943599`. Its 68 control cases / 4,516 frames pass; the task branch now passes all 64 map cases / 18,058 steps. Only the two Swim Team cases retain their prior two-frame differences from the working preview. This restores the preview's existing 4.8 m/s lateral transfer setting to the older task branch; it does not retune an existing value or change the shared checkout's tuning. Source-profile exits use their own angle rule with no added lateral strafe. The default 960-frame movement trace remains byte-identical.

The earlier “first-board” label was inaccurate: Tony's base stats are 3/7/7/4, and the selected 4/8/8 profile includes the first STAT UPGRADE. The validated selected values are retained; the zero-bonus starting board does not add a stat point. The following pass adds the original balance recurrence, soft-corner projection and landing-height policy. Complete state-boundary timing, catch eligibility, steering/braking and fixed-point rounding remain incomplete; this is not a finished 1:1 movement port.

## Source balance, corners and roof landings

Iteration 30 adopts the source balance implementation from local dependency `f8995088`, enabled only when a profile supplies its balance stat. School selects stat 5, consistent with its existing first STAT UPGRADE profile. Balance runs the original integer recurrence at 30 Hz: neutral input arms steering after a catch, the same-chain catch adds 40 difficulty ticks, a different chain removes 30 with a floor of zero, air retains the history, and supported ground clears balance and elapsed rail time. Crossing either ±4000 balance boundary triggers a bail without the fork's grace period. Existing levels without this optional stat retain their authored balance model.

Eighteen traces covering three stats, two random seeds and 30/60/120 Hz match statements compiled directly from the pinned original C++. An unattended integration grind bails at frame 123; ordinary countersteering sustains 1,200 frames / 20 seconds, with an 18.025% peak needle deflection. The review pilot reads actual needle velocity because differentiating the 30 Hz needle's held 60 Hz display samples produces alternating zero and double velocity. Its feedback gains were adjusted for the longer source grinds; no production balance constant was tuned to make the pilot pass.

The original curved boundary chain 797 takes 754 steps through its complete grind and grounded rollout, with a 14.375% maximum needle deflection. All 14 original bends retain the incoming velocity's projection onto the next segment, verified against their source coordinates. The first two reduce speed from 23.4326 to 21.2342 to 20.8250 m/s. Six separate forward/reverse soft- and hard-corner fixtures also pass. No source node is moved or smoothed away.

The original roof above the lower courtyard provides a real 36.7405 m drop. The fork's generic height/impact rule automatically bailed on contact at step 184. The original `HandleBailOnLanding` judges trick/orientation conditions; the inspected source contact path does not impose this height penalty. School now uses the existing `hugeDropBail: false` option, with its minimal branch support taken from local dependency `039a04ee`. Default and explicit-true levels still bail. All 183 pre-contact frames are identical with the option off, followed by a supported landing and 30 ordinary rollout frames. Source geometry, flight parameters and global tuning are unchanged. The flag does not disable trick, wall or rail landing judgement. Falling outside the campus still crosses the kill plane and respawns on supported ground in 136 steps. The review includes Boundary grind and Roof drop shortcuts. K/L checkpoint warps work when the developer controls are shown with M.

Current validation covers **20 cases / 11,686 steps**, matching exactly across both native runtimes and lite/full browsers. The continuous 35-waypoint campus route remains 980.931 m / 6,293 steps. Evidence and runtime hashes are in `../performance/school-miami-reference-balance-landing.json`, with complete native and browser reports alongside it. The accepted 2× map still passes its 64 cases on the task branch (18,058 steps), byte-identical to iteration 29, and the 960-frame default trace is unchanged.

The balance recurrence uses the fork's deterministic random stream and runs at the existing post-step state boundary; native RNG and complete state scheduling are not claimed exact. Source corner speed projection is preserved, while the underlying motion integration remains continuous at 60 Hz. Original art, source rail-catch eligibility, contact/steering/braking details and retained-version verification remain open.
