BONEMAN offline desktop edition.

Download the artifact matching your computer: macOS arm64 for Apple Silicon, macOS x64 for Intel, Windows x64, or Linux x64. The browser runtime and game assets are included. Installation and play require no downloads. Updates are complete replacement installers; saves remain in the separate BONEMAN application-data directory.

Before publishing this draft, attach the minimum-hardware performance and offline installation results described in docs/OFFLINE_DESKTOP.md. Confirm the matching SHA256SUMS, macOS signatures/notarization tickets, and Windows installer signatures. CI frame times on virtual runners are functional checks, not hardware performance certification.
