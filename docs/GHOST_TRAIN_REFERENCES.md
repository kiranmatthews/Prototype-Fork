# Spooky Island design references

The chamber redesign uses the actual film's production work and attraction
imagery rather than relying on one low-resolution scene capture.

| Reference | Use in this level |
| --- | --- |
| [Jacinta Leong — Scooby Doo production artwork](https://www.jacintaleong.com/film/scooby-doo) | Spooky Castle foyer plans and elevations, torture-chamber levels, pointed studded doors, inset turret details, irregular polygonal walls and insect-wing leadlight windows. |
| [Suza Maybury — Warner Bros set decoration](https://www.behance.net/gallery/1472079/Scooby-Doo-Set-Decoration-Warner-Bros) | Original castle-ride and banquet set dressing; useful as a source link even when its image host blocks automated retrieval. |
| [Movie World — official Scooby-Doo Spooky Coaster](https://movieworld.com.au/attractions/scooby-doo-spooky-coaster) | Close monster-faced burgundy/gold cars, rough stone portals, saturated blue/magenta lighting, and theatrical dinner/armour staging. |
| [The Dinner Show — official Movieclips excerpt](https://www.youtube.com/watch?v=mEzXLJL48nA) | The film's active banquet sequence and mechanical scare timing. |
| [Live Design — the original 2002 attraction](https://www.livedesignonline.com/see-movie-doo-ride) | Moving-viewpoint show design, carved monster-mouth reveals, emerald illumination and layered depth. |
| [Scooby-Doo HD scene gallery](https://movie-screencaps.com/scooby-doo-2002/) | Additional film frames for private visual study. |

The original reference images remain research material and are not shipped as
game art. Runtime models and their textures are original Meshy generations.
ImageGen is used for original scene/chamber mockups, with exact prompts saved in
[ghost-train-concepts/prompts.json](ghost-train-concepts/prompts.json).

The three mockups establish the authored composition targets:

- [Boarding and axe reveal](ghost-train-concepts/boarding-axe-room.png): compact open cars, a large face portal, close armour alcoves and a low chandelier.
- [Banquet theatre](ghost-train-concepts/banquet-theatre.png): an octagonal feast reveal, a raised U-shaped dais, close cake/turkey performances, carved tables and dramatic leadlight.
- [Hanging-rail crypt](ghost-train-concepts/hanging-rail-crypt.png): layered ruined ledges, genuine interrupted rail grinding, a clockwork side stage and a framed monster-mouth exit.

These images are concept mockups. Validation and actual gameplay captures are
kept separately so the rendered game can be judged against the intended design.
