# Recording-driven flame revision

The user supplied two recordings, resolving the earlier reference blocker. Both were decoded and examined in presentation order. See [reference-study.md](reference-study.md) for observations, source timestamps and limits.

The selected art now consists of three independent families of twelve separately generated cels. Every selected original, prompt and reference version is recorded in [generation.json](generation.json). Native packing is pixel-exact. Medium 10 and broad 11 were redrawn after identifying abrupt progression in the initial contact sheets.

Source and in-scene review are complete. The runtime uses native proportions and per-frame foot registration, with shader wobble removed and interpolation off by default. All source drawings and seams can be inspected using the scrubber, Step and Single drawn flame. The existing Jak heat implementation is retained.

Local browser checks cover the eight arrangements, three source cycles, all frame steps, hue changes, slow playback, frame blending, heat toggles, normal and native rendering, portrait and short landscape layouts. Pause and zero-strength heat are pixel-identical to their controls; active heat visibly refracts the background. See [browser](browser) for captures and measurements.

Production build and release verification are recorded in the iteration log and release report when complete. The previous published atlas is retained as historical source; it is no longer loaded by this exhibition.
