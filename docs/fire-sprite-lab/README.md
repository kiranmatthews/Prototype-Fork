# Fire Sprite Lab

Open `fire-sprite-lab.html` from **Labs → Fire Sprite Lab**. The collection shows eight arrangements; selecting a card isolates that exhibit for orbiting. Space pauses playback while the scene has focus; Left/Right change exhibits and Escape returns to the collection. The inspector provides slow motion, stepping, hue presets and a slider, interpolation, grid visibility, heat strength and 720p/MAX rendering. Compact screens page the collection and scroll only the inspector. Reduced-motion preferences start playback paused.

The built-in `image_gen` tool created `public/fire-sprites/flame-atlas.png`: a genuine-alpha 1254 × 1254 PNG containing sixteen frames in a 4 × 4 grid. [The complete generation prompt](imagegen-prompt.txt) records the Crash Bandicoot 4 style brief. This is newly generated artwork, not extracted game art. The original generated file is retained unchanged in the project.

`src/spriteFire.ts` reuses that one texture for all 157 camera-facing quads across the eight emitters. Per-instance timing, scale, position and direction create torch, bonfire, wall, ring, jet, wisp, vortex and ember arrangements. A shader applies hue transforms and optional premultiplied-colour frame interpolation; source alpha is retained. Instance ordering follows camera depth. There are no flame meshes, distance-dependent geometry substitutes or new external asset dependencies.

`src/fire-lab/lab.ts` attaches the emitters to the unchanged `FlameHeatDistortion` and `writeTorchHeat` implementation already used by the game. The same eleven-slice Jak framebuffer distortion draws behind the sprites with foreground depth testing. Two heat streams per exhibit keep the complete collection within the existing 512-pocket budget (at most 288 pockets); focus mode needs at most 36. Playback pause and stepping use one shared clock for sprites and heat.

Validation is reproducible with `tools/fire-sprite-lab/browser.mjs <base-url>`. Set `PLAYWRIGHT_MODULE` and `SHARP_MODULE` to installed package entry points when they are not in local module resolution. The focused browser pass checks all eight exhibits, source texture sharing, actual pixel changes for animation/hue/heat, pixel-exact pause and zero-strength heat identity, lite and full rendering, resolution controls, viewport bounds, touch, reduced motion, orbit, the Labs entry and console/WebGL errors. `npm run build`, `npm run check:release` and `node tools/test-tool-directory.mjs` validate the production artifact. No level data, movement tuning, game torches or unrelated labs are replaced.
