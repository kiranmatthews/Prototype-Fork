# Campaign crate and enemy review — complete

Reviewed **all 34 playable courses in the game UI and all 24 unique linked bonus rooms**, one course at a time, against the [Gameplay Design Bible](../../GAMEPLAY_DESIGN_BIBLE.md). The five unbuilt placeholder slots are excluded. The final [UI roster check](coconut-cart-rally/campaign-coverage.json) confirms this scope.

Changes group ordinary rewards into readable collections, put lives on optional risks, preserve or test finite launch tools, and repeat readable enemy counters. Appropriate boss, competition and fast-route layouts are retained where adding ordinary crate or combat structures would conflict with their mode. Coconut Cart Rally closes the pass by moving four obstructed item rows.

Each linked review records its design decisions, preservation checks, native and browser evidence, and limitations. Many main-course collection tests use separately staged approaches; completion does not claim one continuous all-box campaign run. Bonus wrong-order, failure and retry behavior is tested where applicable. Per-course timing overruns are recorded in the [iteration log](../../LEVEL_ITERATIONS.md).

Final required level checks, build and release-size gate pass: `44bce024d7abb2edb14e`, **959,322,064 / 1,000,000,000 bytes**. [Play the published fork](https://kiranmatthews.github.io/Prototype-Fork/). Publishing uses `origin/main` and the existing GitHub Pages workflow.
