# Rejected island composition studies

These six generated studies were rejected by the user. They are retained only as an archive of the attempted direction and must not be used as art targets.

The supplied [Crash 1 N. Sane Trilogy map video](https://www.youtube.com/watch?v=nPPj4RW4zDo) is the composition reference. Review the actual playable map at native resolution: a compact landmass, a clear coastal route, scenery joined to the terrain, and the skater in the foreground.

Motu was regenerated with the reference frame supplied to ImageGen. The other five studies use that corrected Motu image as their composition reference. Generation used the built-in `image_gen` tool. Exact variant prompts and original output paths are in [prompts.json](prompts.json).

The useful constraints are a single readable landmass, one dominant central form, a foreground skater, a clear narrow coastal route, and a few large landmarks joined to the landscape. These constraints come from the video; the generated images are not an implementation specification.
