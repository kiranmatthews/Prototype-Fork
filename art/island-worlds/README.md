# Compact island composition studies

These six replacement studies use the compact composition of the supplied [Crash 1 N. Sane Trilogy map reference](https://www.youtube.com/watch?v=nPPj4RW4zDo). The earlier sprawling concepts were rejected and are not retained in this art set.

Motu was regenerated with the reference frame supplied to ImageGen. The other five studies use that corrected Motu image as their composition reference. Generation used the built-in `image_gen` tool. Exact variant prompts and original output paths are in [prompts.json](prompts.json).

The useful constraints are a single readable landmass, one dominant central form, a foreground skater, a clear narrow coastal route, and a few large landmarks joined to the landscape. The images guide composition; their invented details do not all exist in the playable map.
