# Motion study assets

The user authorized publication of these existing playtest references on 8 November 2026. They support the Jump A/B/C/D comparison, the Skate playtest and the 218-clip source viewer in Labs.

The samples, six jump sound placeholders, eco textures and optional Jak comparison model are copied from the approved local study exports. Decoded source hashes and sizes are recorded in provenance.json. Motion banks and the complete model use lossless gzip packing; decoding reproduces the original bytes exactly. No disc images, original game banks, extraction caches or local filesystem paths are included. The original game assets retain their respective owners' rights; the repository's source-code license does not relicense them.

The independently generated board-scribble atlas remains in src/skateReferenceLab/assets with its generation provenance. Runtime URL resolution supports both a site subdirectory and explicit private development-server overrides.
