# Carlisle harbour ambience

Both sources are released under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

- **Sea and river wave sounds**, RandomMind (2019):
  https://opengameart.org/content/sea-and-river-wave-sounds
  Original: `VistulaShort_0.mp3`, a field recording from the Vistula river.
  Carlisle uses a 44-second stereo loop from the 38–87 second excerpt, with a
  five-second equal-power overlap, low-frequency cleanup, level adjustment and
  a tiny PCM boundary repair. Saved as `harbour-water.wav`.
- **wind1**, Luke.RUSTLTD (2010):
  https://opengameart.org/content/wind1
  Original: `wind1.wav`, synthesized wind made in PureData from an Andy Farnell
  tutorial. Carlisle uses a 55.9-second mono loop with a four-second equal-power
  overlap, low-frequency cleanup, level adjustment and PCM boundary repair.
  Saved as `coastal-wind.wav`.

Both runtime files are 32 kHz, 16-bit PCM. The complete downloads and reproducible
mastering tools are retained in the authoring repository. No purchased or
restricted audio is used for these layers.
