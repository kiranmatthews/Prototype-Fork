# Quaternius swimming motions

`Swim_Fwd_Loop` and `Swim_Idle_Loop` come from Quaternius’s free Standard Universal Animation Library, uploaded by the author to [OpenGameArt](https://opengameart.org/content/universal-animation-library). Both clips are included in the original 2025 CC0 release; no paid Pro/Source files were used.

The checked-in TypeScript samples retain 30 FPS source timing, 22 semantic body joints and cyclic pelvis displacement. The importer supports the original Blender DEF bone names as aliases of the modern UAL rig. Runtime transitions blend the source poses; water movement and buoyancy are controlled separately by the game.

See `LICENSE.txt` and `provenance.json` for the original licence, exact source hashes and reproducible import details.
