# Controller prompt artwork

The PNG files are copied unchanged from the asset pack supplied by the project
owner in `Downloads/Source`. Selected variants:

- Keyboard/mouse: Dark
- PlayStation 4: Stylized (coloured face-button symbols)
- PlayStation 5: Default (its monochrome face-button symbols)
- Xbox: Default (coloured face-button letters)
- Nintendo Switch: Default

No license or attribution text was included in the supplied Source directory.
These third-party PNGs are not covered by the repository's Apache license;
retain the pack's original rights and confirm its distribution terms before
production release. This notice does not grant additional rights.

The pack contains no Steam Deck family or Xbox Menu glyph. The project's
small SVG supplements supply Menu and Deck L1/R1/L2/R2 shapes. Deck face-button
prompts reuse the pack's Default white ABXY glyphs without tinting them.
Other supplied images keep their original filenames for provenance.

Re-import with `node tools/import-input-prompts.mjs /path/to/Source`.
