# Haunted castle ghost train — original Meshy assets

The models in this directory are original Meshy T2 Smart Topology generations
requested by the project owner for the indoor haunted castle ghost train.
They use low polygon geometry with compact embedded hand-painted base-color
textures. Generation prompts, task records, hashes and measured bounds are
recorded in `tools/ghost-train-assets/` and the adjacent provenance JSON files.

**Models created with [Meshy](https://www.meshy.ai/) —
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).**

This conservative attribution is retained because account subscription
ownership was not separately inspected during the task. It can be updated
if the owner later records paid/private ownership provenance.

Coordinates: Y-up, +Z-forward, ground Y=0, centered X/Z, maximum dimension 1.
Runtime collision stays in the authored level components; no provider
credential or remote dependency is present in these files.
