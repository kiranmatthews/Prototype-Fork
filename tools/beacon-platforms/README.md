# Start and finish beacon platforms

The two new reference images were generated with the built-in `image_gen` tool
on 25 October 2026. Exact prompts are in `prompts.json`; the original images are
`references/arrival-green.png` and `references/finish-green.png`. Following the
user's correction, both designs faithfully carry the world map's vivid green
center, continuous luminous white rim and simple dark stepped base into the
main-level arrival and finish pads. The initial teal/gold compass designs were
rejected and are not shipped.

Both meshes were generated by Meshy image-to-3D, `meshy-t2` smart topology,
with a 6,000-triangle target and 2K PBR textures. Each accepted job cost 15 credits
(30 credits for the final pair; 60 including the rejected first pair).
`tasks.json` records the task IDs and reference hashes. The first
request was rejected with HTTP 400 because `remove_lighting` is unsupported by
smart topology; the official operation journal confirmed no task was created.
Only then was the corrected request submitted. Signed provider responses and
original authoring GLBs remain in ignored `.img2threejs/beacon-platforms/`.

`meshy_jobs.py` uses the repository's existing official Meshy CLI adapter.
Set `ENEMY_MESHY_CLI` to an installed official CLI and `ENEMY_NODE` if needed;
authentication stays in the CLI's existing local account configuration.

```sh
python3 tools/beacon-platforms/meshy_jobs.py status arrival-green finish-green
python3 tools/beacon-platforms/meshy_jobs.py download arrival-green finish-green
python3 tools/beacon-platforms/pack_assets.py
node tools/test-beacon-platforms.mjs
node tools/test-warp-pad-batching.mjs
node tools/test-level-warp.mjs
node tools/test-beacon-platforms-browser.mjs http://127.0.0.1:5461/
```

Packing preserves Meshy's triangle connectivity, UVs and PBR artwork. It fits
the original 3.23 m footprint and 0.733 m standing plane, flattens the central
standing surface and limits decorative rim relief to 1.5 cm. Diffuse maps remain
2K; normal and roughness/metalness maps are 1K. A restrained emissive fill reuses
the diffuse texture. Runtime files and SHA-256 provenance live in
`public/props/beacon-platforms/` (5,927 / 6,374 triangles, one draw per pad,
2,707,508 bytes combined).

The original three collider meshes, start/finish flags, gate position, spawn
height and movement rules remain authoritative. Artwork uses the shared asset
queue and reference-counted cache. Level presentation waits for it before
revealing gameplay; a loading failure retains supported fallback stone.
Disposal of the collider owner releases pending or loaded artwork, while a
graphics-context reset retains the lease for reupload.

Open `tools/beacon-platforms/review.html` through Vite to inspect the actual
runtime pair. Add `?kind=arrival` or `?kind=finish` for a single model. Screenshots
and the browser report are in `docs/beacon-platforms/`.
